# Wattómetro

PWA gratuita para monitorizar e otimizar o consumo elétrico de uma casa portuguesa, a partir de um **Shelly** instalado no quadro elétrico e/ou do CSV de consumos a 15 minutos exportado do Balcão Digital da **E-Redes**.

Não é mais um gráfico: são **conclusões em euros e ações concretas** — potência contratada certa, tarifário mais barato para o teu perfil real, custo do consumo fantasma, fatura prevista do mês, aparelhos a degradar e registo de problemas de tensão para reclamar. IA opcional com a tua própria chave.

## Privacidade

- Os dados ficam numa conta Cloudflare do dono da instalação, na UE. Sem estatísticas nem registos remotos com dados de consumo.
- A app funciona sem IA. Quando usada, a IA só recebe resultados já calculados, nunca as séries de consumo em bruto.
